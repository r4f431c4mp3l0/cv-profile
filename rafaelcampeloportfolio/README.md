# rafaelcampeloportfolio

Portfólio online e currículo de Rafael Campelo. Site estático, sem dependências e sem etapa de build.

## Como atualizar

Todo o conteúdo (resumo, projetos, experiências, formação, habilidades e contatos) fica em `js/data.js`.
Imagens de projetos vão em `assets/` e são referenciadas no campo `imagem` de cada projeto.

## Como ver localmente

Abra `index.html` no navegador.

## Currículo em PDF

O botão "Baixar currículo (PDF)" abre a impressão do navegador com um layout próprio para o currículo; escolha "Salvar como PDF".

## Publicação

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / raiz.
